# 系统设置重构方案（2026-11-13）

## 现状问题

- 一页长滚动：直连 API 模式下约 3500px，七类东西堆在一起：自定义提示、技能、后端选择、模型表单、执行权限、天气、性格职业。
- 同一个字段有两个开关："执行模式"四宫格和"工具调用二次确认"都在改 `execution_mode`。
- 保存行为不一致：思考深度、搜索源、流式模式改了立即保存；执行模式、免确认工具改了不保存，要滚到底点"保存配置"，离开页面就丢。
- 控件位置乱：预设填充在表单最底下（应该挨着接口地址），Computer Use 开关夹在模型表单中间。
- 每个字段都是"标题 + 控件 + 一段灰字"，视觉上没有层级。

## 信息架构：侧边栏子列表

"系统设置"改成和"对话互动"一样的可展开分组（复用 `.sidebar-group` / `.sidebar-subnav` / `.sidebar-subitem`）：

| 子项 | 内容 |
|---|---|
| AI 后端 | 四个后端卡片；当前后端的连接状态与操作（Claude Code 状态、Codex / DSH 组件、直连 API 当前配置摘要） |
| 模型接口 | 直连 API：左边配置列表，右边编辑器（连接 / 推理与搜索 / 协议），底部测试与保存 |
| 执行权限 | 直连 API 执行模式（四选一，即时保存）、免确认工具（即时保存）、Computer Use |
| 角色设定 | 性格、职业、自定义系统提示 |
| 技能 | 技能列表与激活切换 |
| 天气提醒 | 开关、城市、接口、测试与保存 |

- 点"系统设置"进入上次停留的子页（存在 localStorage `dash.system-section`），同时展开子列表；箭头只负责展开或收起。
- 其他入口（聊天栏"设置"按钮、斜杠命令 /skills）直接跳到对应子页。

## 页面版式

- 页头：小标题"系统设置"+ 子页名 + 一句说明，和其他页面统一。
- 内容区：分区卡片（`sys-section`）。卡片头是标题、说明和可选的右侧操作；卡片体是设置行（`sys-row`），左边标签加说明，右边控件，行间用细分隔线。
- 小选项集（思考深度、流式模式、API 格式）用分段控件；大选项集（执行模式、性格、职业）用卡片网格。
- 模型接口页在宽度足够时双栏（列表 260px + 编辑器），窄窗口自动变单栏。
- 不常改的"协议"（流式 / 格式）和兼容性报告放进可折叠区域。
- 当前后端不是直连 API 时，模型接口和执行权限页顶部给出提示条和"切换到直连 API"按钮，避免用户改了不生效还以为是 bug。

## 行为修正（随重构一起做）

- 执行模式、免确认工具改为即时保存（复用 `updateExecutionMode`，免确认工具静默保存）。
- 删除重复的"工具调用二次确认"开关。
- 技能 store 在后端返回非数组时退回空数组，避免整页渲染崩溃。
