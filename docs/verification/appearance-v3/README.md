# 配色提亮 + 背景重做 + 外观页视觉重做（v3）

日期：2026-11-13

## 一、先说诊断：为什么"暗"和"廉价"

我没有凭感觉调，而是写了两个量化脚本量实际渲染出来的像素。

### 亮度测量（`measure2.cjs`，采样整页像素转 OKLab）

| 对象 | avgL | avgC | entropy |
| --- | --- | --- | --- |
| 改前·外观页 | 0.928 | 0.014 | 0.64 |
| 改前·背景·极光 | 0.923 | 0.015 | **0.60** |
| 改前·背景·可爱 | 0.931 | 0.014 | **0.22** |
| 改前·背景·科幻 | 0.926 | 0.012 | **0.24** |
| 改前·背景·简洁 | 0.941 | 0.007 | **0.21** |
| 参考照片 | 0.88 | **0.021** | — |

结论：**问题不是亮度低，而是"平"和"没颜色"**。

- avgL 0.93 比参考照片还亮，所以不是真的暗
- 但 95% 像素挤在最亮那两档（brightPct 95%），没有明暗过渡 → 视觉上"死板、闷"
- avgC 只有 0.014，参考照片 0.021 → 看着像"脏白纸"，这是"廉价"的直接来源
- 交互背景 entropy 0.2~0.6 → **几乎看不出画了什么**

### 结构审计（`audit.cjs` / `pixel-contrast.cjs`）

- 37 个按钮文字是纯黑 `rgb(0,0,0)`：全局 `button` 没有 `color: inherit`，浏览器默认黑
- 10 处对比度不达标：白字压在亮青 `#4bb2b8` 上只有 2.42:1
- 所有卡片圆角、描边、投影都在同一档 → 没有视觉主体

## 二、配色：拆成三个角色，而不是一个颜色打天下

之前反复在"亮"和"可读"之间来回摆，是因为把两个角色塞进了一个颜色：

- 主色作**色块**（按钮底、选中态）→ 希望它亮、有颜色
- 主色作**小字**（kicker、标签）→ 希望它深、对比够

硬取中间值，两边都不达标。改成 Material 3 的 tonal 方案：

| 令牌 | 值 | 用途 | 对比度 |
| --- | --- | --- | --- |
| `accent` | L 0.66 / C 0.082 | 色块、选中态、装饰 | 纸面 2.7:1（仅作图形） |
| `onAccent` | ink-900 | 压在 accent 上的文字 | **7.0:1** |
| `accentStrong` | L 0.545 | 需要白字的实心按钮 | 白字 **4.9:1** |
| `accentText` | L 0.45 | kicker、标签等小字 | 纸面 **5.2:1** |

另外两处关键修改：

1. **INK 色相 264° → 60°**。原来是冷蓝灰，压在奶油纸面上互相打架、显脏；改成同色系暖灰后整页通透。
2. **button 补 `color: inherit`**。这一条直接消掉 37 处纯黑文字。

12 套主题全部按新角色重新生成（primary 保证白字 ≥5.0:1，用户气泡 ≥5.7:1）。

## 三、对话背景：从"一层平的图案"改成"有光的画面"

### 根因

光场（提亮层）画在图案**之后**，0.30 alpha 的 screen 把图案一起洗掉了 ——
所以 5 个背景 entropy 只有 0.2 左右，等于一片白。

### 改法

1. **光场改成"提亮为主"**：不再用 multiply 压暗做纵深（那会把底部压到 L 0.65，像蒙了层土），
   改成 screen 提亮 + 极轻的明暗（8%）+ 角落收边（12%），加顶部柔光带和左上光斑
2. **提亮层强度从 0.30 降到 0.13**，不再洗掉图案
3. **各背景图案逐个加深**：
   - 极光：光柱 alpha 0.42→0.75，峰值 ×1.9；星点提亮并换成更深的青
   - 水墨：远山墨色 alpha 0.115→0.30，色调加深
   - 可爱：花瓣 35→52 片，颜色从极浅粉 `#eddfe5` 换成玫粉 `#b8768f`，alpha 0.3→0.85
   - 科幻：六边形网格原来只在鼠标附近才画（`glow` 初始 0），补常驻基线 0.18
   - 简洁：点阵间距 24→18px
4. **颗粒层改用 `overlay`**，避免在亮底上压灰
5. 修掉一个死分支：`minimal` 在 `draw()` 里有**两份**，第一份半透明底命中后第二份永远走不到

### 效果

| 背景 | entropy 改前 → 改后 | avgL |
| --- | --- | --- |
| 极光 | 0.60 → **0.99** | 0.902 |
| 水墨 | 0.78 → **0.91** | 0.915 |
| 细雨 | 0.96 → 0.65 | 0.920 |

极光 avgC 从 0.015 提到 0.025（超过参考照片 0.021），非纸白像素占比 78%。

## 四、外观页：从"一叠白盒子"改成"有主体"

量化依据：整页 1478px 高，hero 只有 296px，剩下全是同款圆角白卡。

1. **hero 放大成主体**：桌宠 156→210px，标题 27→34px，面板从"白底加一点渐变"改成真正的色场
2. **分区去外壳**：分区标题用大字重（21px）+ 4px 渐变竖线 + 大间距，不再靠描边分层
3. **形象卡选中即抬升**：亮面 + 明确的投影层次 + 3px 外发光
4. **主题做成色票**：色块高度 42→52px，名字缩小到辅助位置
5. **字体颜色做成圆形色点**，比原来的"Aa 方块"更像调色板
6. **两栏布局**：「形象」和「配色」并排，整页从 1706px 压到 1478px
