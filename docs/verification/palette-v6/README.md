# 配色 v6：按参考图结构重做 + 极光/细雨写实化

日期：2026-11-14

## 一、极光：试了 7 版，用视觉模型逐版打分

你的要求是「去查真实极光长什么样」。我读了维基百科 Aurora 条目，
拿到真实的发射线数据：

| 波长 | 来源 | 高度 | 颜色 |
| --- | --- | --- | --- |
| 557.7 nm | 氧原子 | 100–150 km | 绿（最常见） |
| 630.0 nm | 氧原子 | 200 km 以上 | 红 |
| 427.8 nm | 氮分子 | 最低边缘 | 蓝紫 |

然后用本机的 `codex`（有视觉能力）逐版看截图打分，避免只靠自己"感觉"：

| 版本 | 做法 | 评分 | 被指出的问题 |
| --- | --- | --- | --- |
| v1 | 均匀竖条纹 | — | 像磨砂玻璃 |
| v2 | clip 裁剪 + fillRect 射线 | — | 硬边、扫描线 |
| v3 | 光斑累积 | 2/10 | "霓虹光柱 + 白芯" |
| v4 | 广义飘带 | 3/10 | 折叠像液体 |
| **v5** | 飘带 + 稀疏射线 + 暗角 | **6/10** | 边缘偏锐 |
| v6 | 锥形射线 + 大椭圆擦除 | 5/10 | 出现大团白斑 |
| v7 | 小半径擦除 | 3/10 | 边缘变串珠状 |

**结论：v5 是最高分，v6/v7 的"擦除柔化"是错误方向** ——
`destination-out` 在 `lighter` 叠加层上会留下边缘颗粒，反而更假。
最终保留 v5 结构，删掉后续所有擦除改动。

当前极光的结构（和真实照片一致）：
- 深海军蓝夜空 → 地平线青灰
- 星点只在上半部（地平线附近有光污染）
- 2~3 条宽阔飘带，下缘是折叠曲线（三层正弦叠加）
- 亮度集中在下缘（对应 100km 沉降边界），向上快速衰减
- 稀疏竖向射线融入飘带（不是独立光柱）
- 紫红只出现在飘带顶部（630nm）
- 地平线地形剪影 + 山脊反照
- 镜头暗角

## 二、细雨：做成「隔着湿玻璃看窗外城市」

我先按第一版做了"玻璃水珠"，用 codex 评审得到 4/10，被指出
"read as decorative bubbles, no recognizable exterior"。
于是重做成现在的结构：

1. **窗外（全部失焦）**：阴天云层、一排楼房轮廓、暖黄窗格灯光、近景树冠
2. **窗外的雨（也失焦）**：细短雨丝
3. **玻璃层（清晰）**：不均匀薄雾 + 干湿斑驳
4. **微水珠**：成簇分布（8~14 个簇心，高斯散开），带实心高光点
5. **大颗水珠**：三档尺度、不规则椭圆、下缘暗边、内反射亮弧、左上高光、下滑湿痕
6. **水流沟痕**：蜿蜒、越往下越宽、右侧细高光、末端坠珠
7. **玻璃顶部窗光**

关键点是**焦点策略**：玻璃清晰、窗外模糊。
codex 复评后从"装饰气泡"变成 6/10「the rain-covered glass works」。

## 三、配色：找到了"灰暗"的真正数学原因

用 PIL 逐像素量化你的参考图（1392×604）：

| 指标 | 参考图 | 我之前的版本 |
| --- | --- | --- |
| avgL | 0.955 | 0.925 |
| 纯白 `#ffffff` 占比 | **63.4%** | 0 |
| 高饱和带占比 | 12.0%（C 0.10~0.23） | 0.4% |
| 暗部（L<0.5） | 0.4% | — |

参考图的结构是 **「大面积纯白 + 一小块高饱和彩虹带」**。
而我之前的做法是"整体调成中低饱和"（C 0.02~0.03）——
**这是最糟的组合：既失去了白纸的干净，也没得到颜色的冲击力。**

所以最终定稿策略：
1. **底色回到干净近白**（`#fefefd`，avgL 0.94）
2. **侧栏、页头、外观页 hero 三块大色块**用高饱和主题色（0.42 alpha）
3. **强调色彩度提到参考图量级**：C 从 0.117 → **0.165**（参考图青是 0.123、紫是 0.230）

### 数值变化

| 项 | 之前 | 现在 |
| --- | --- | --- |
| 纸面 | `#fcfbfa` | `#fcfbfa`（已到白） |
| accent 彩度 | 0.117 | **0.165** |
| warm 彩度 | 0.128 | **0.180** |
| 侧栏主题色 | 0.22 | **0.42** |
| 页头主题色 | 0.24 | **0.34** |
| 外观 hero | 0.34 / 0.40 | **0.62 / 0.72** |
| 文字 ink-800 | L 0.34 | L 0.355（更深） |
| 说明文字 | ink-600 | **ink-650**（对比 4.38→5.2） |

### 顺手清掉 288 处旧配色残留

扫描发现 `dashboard.css` 里还有 288 处硬编码的旧配色 rgba：
粉紫 `194,156,173`、蓝紫 `123,132,159`、旧青 `96,148,151`、
旧暖 `187,129,102`、旧墨 `52,56,63`。

这些不跟主题走，而且色相和当前主题冲突 —— 是"脏、闷"的隐藏来源。
全部替换成 `var(--dash-accent-rgb)` 等主题变量。

### 修掉的两个测量工具 bug

1. `theme-probe.cjs` 用 `sidebar.slice(-60)` 取侧栏底色，取到的是各主题共用的
   白色高光层 → 一直误报"主题没跟随"。改成取整串。
2. 我自己加的极光 `ctx.filter = blur(...)` 实测把评分从 6/10 拉到 3/10，
   已回滚。**这次的教训是：柔化必须靠形状与透明度，不能靠全局模糊。**
