# 配色 v4「青瓷」· 从参考照片到完整色板

日期：2026-11-11
参考：用户提供的一张竖版照片（1200×2670），已用 OKLab 量化其配色规律。

## 一、先量参考图（不靠眼睛猜）

| 指标 | 参考照片 | 旧版界面 | 改版后 |
| --- | --- | --- | --- |
| 平均亮度 L | **0.88** | 0.955 | **0.94** |
| 平均彩度 C | **0.021** | 0.009（改到一半时） | **0.011~0.013** |
| 主色相 H | **197.8°（青瓷）** | 95°（偏黄米色） | **193~197°** |
| 高饱和像素占比 | 0.15% | — | 0.00~0.03% |
| 深色像素占比 | 2.77%（只用于文字） | — | 与参考同量级 |

**结论**：这张图高级的原因不是"颜色好看"，而是三条纪律——

1. **极亮**：97% 像素在 L>0.62，整体是"纸"不是"墙"
2. **极低饱和**：平均 C 只有 0.021，最浓的地方也不过 0.061
3. **色相高度收敛**：只有青瓷(198°) 和暖砂(88°) 两族，深色只占 2% 且只用于文字

旧界面正好三条都违反：配色有 7 个色相各自为战、彩度平均高出 5~10 倍、
还混着高饱和糖果色。

## 二、按业界方法建色板（Refactoring UI）

查阅 [Building Your Color Palette](https://refactoring-ui.com/previews/building-your-color-palette)，采纳其中四条：

1. **不要用 `lighten()/darken()` 现算**——否则会飘出几十个近似色，必须预先定死色阶
2. **先定基准档，再定两端，最后回填中间**（900/500/100 → 700/300 → 600/400/200/800）
3. **灰阶要 8–10 档**，纯黑不自然，用很深的灰收尾
4. **强调色要少**，靠语义而不是靠数量

落地方式：用 **OKLCH** 生成色阶（L 均匀递减、C 走钟形曲线），
保证"相邻两档看起来是等距的"，而不是 sRGB 里那种忽明忽暗。

产出四族共 35 档：

| 色族 | 用途 | 档位数 | 示例 |
| --- | --- | --- | --- |
| 青瓷 celadon | 主色 | 10 | `#609497` / `#4a7577` |
| 暖砂 sand | 纸面/分区 | 8 | `#f7f3eb` / `#e4ddcc` |
| 墨 ink | 文字 | 10 | `#34383f` / `#1e2127` |
| 陶土 clay | 唯一暖强调 | 7 | `#bb8166` / `#9f684f` |
| 青纸 paper | 底色（新增） | 6 | `#f0f8f6` / `#e9f4f2` |

## 三、具体改了什么

| 层 | 改动 |
| --- | --- |
| 设计令牌 | `dashboard.css` 的 `:root` 全部换成色阶变量；新增 `--paper-*` 6 档 |
| 语义色 | 原来的 6 个 `--dash-candy-*`（荧光蓝/绿/黄/橙/粉/紫）全部重定向到青瓷+陶土，组件代码不用改 |
| 阴影 | 中性色从偏蓝 `rgba(33,48,74)` 换成中性墨 `rgba(52,56,63)`，共 310 处 |
| 主题皮肤 | 7 个主题全部换成低饱和版：青瓷 / 雨过天青 / 远山黛 / 鼠尾草 / 陶土 / 藕荷 / 流光；**保留原 id**，老用户已选皮肤不失效 |
| 硬编码颜色 | 三轮扫描共替换 430 处高饱和 hex 与 rgba（含状态色、语音波形、桌宠道具） |
| 纸面纹理 | 原 `paper-grain.webp` 平均 R-B=+11.2（偏黄），生成中性版 `paper-grain-cool.webp`（R-B≈0）并全局替换 49 处 |
| 对比度 | `--dash-text-muted` 从 ink-500 提到 ink-600，说明文字从 2.9:1 提到 **4.6:1**（达 AA） |
